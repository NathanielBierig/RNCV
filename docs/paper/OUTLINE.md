# Paper outline: "What makes a UFC rear-naked choke finish? A pre-registered study"

Thesis-style write-up for the public release ([ROADMAP](../ROADMAP.md), "Public release" item 3). This file is the skeleton. Each section names its source in the repo and what's still missing. The draft gets written once the data reach ~150 attempts (PREREG target). Before that it can only be a pilot report.

| § | Section | Source in the repo | Status |
|---|---|---|---|
| 1 | **Introduction.** The RNC is the UFC's most common submission. Coaches agree on its details (arm under the chin, locked grip, leg control, hand fighting), but no study has counted which ones decide the finish. | [EVIDENCE.md](../../research/priors_evidence/EVIDENCE.md) (literature, Stellpflug 2020 timing) | 🟢 material exists |
| 2 | **Pre-registration.** v1.0 frozen before labeling, with dated amendments A1–A4. Why pre-register a sports question at all (prevents finding patterns after the fact). | [PREREG.md](../../research/rnc_science/PREREG.md) | 🟢 |
| 3 | **Data.** Hybrid sampling: finish list, candidate rounds and a random subset. Per-fighter caps, men's divisions only. Live feed only, no replays. | PREREG §2, [FOOTAGE.md](../FOOTAGE.md), `phase3_labels/` | 🟡 random subset not labeled yet (needed for the honest base rate) |
| 4 | **Coding.** Landmark at 2 s after the start, blinded panel, code book with pictures, second rater (κ per factor). | [FACTORS.md](../../research/rnc_science/FACTORS.md), [code book](../rnc_codebook.html), labeler | 🔴 second rater not yet recruited |
| 5 | **Analysis.** Firth logistic regression (H1 arm, H2 legs, H3 two-on-one), profile CIs, cluster bootstrap by attacker; secondary discrete-time hazard model with the bell as censoring. | PREREG §7–8, [prereg_analysis.py](../../research/rnc_science/prereg_analysis.py) | 🟢 script written and tested on simulated data (95% CIs cover 95–100%; at n = 150 an odds ratio of ×2 is detected only ~42% of the time). Runs on real data only at ~150 attempts |
| 6 | **Results.** Odds ratios with CIs and supported / contradicted / inconclusive per hypothesis; exploratory factors (grip type, hidden hand, chin, flattened) clearly marked. | — | ⚪ waits on data (36/150) |
| 7 | **Applied model: the replay overlay.** Finish chance from expert priors + labels (cards as pseudo-data), the choke meter from physiology, leave-one-fight-out validation (Brier vs base rate), the Pantoja–Asakura case study. Kept separate from the confirmatory study. | [MODEL_SPEC.md](../MODEL_SPEC.md), [COACH_REVIEW.md](../../research/coach_review/COACH_REVIEW.md), panel GIF | 🟡 v0.6 / v0.7c done; numbers will change with the labels |
| 8 | **Automatic detection (appendix).** The attempt detector (CLIP + logistic, ROC-AUC 0.74), and why skeleton pose fails in tangled positions (4/48). Negative results reported. | [attempt_detector_v2.md](../../reports/attempt_detector_v2.md), [pose REVIEW](../../research/pose_review/REVIEW.md) | 🟢 material exists |
| 9 | **Limitations.** Broadcast angles hide the hands, single rater so far, selection by outcome (handled by `found_via`), small n, and the coach review is AI opinion, not data. | throughout | 🟢 |
| 10 | **Ethics and data.** No footage redistributed; only derived labels are released. | FOOTAGE.md | 🟢 |

**Format:** Markdown → PDF (pandoc), ~12–15 pages, figures generated by scripts in the repo (forest plot of odds ratios, calibration plot, Pantoja trace, detector ROC).

**Honesty rules for the write-up:** power at n ≈ 150 is ~90% only for big effects (25 points). Smaller effects will come out "inconclusive", and the paper says so. Exploratory findings are hints, never claims.
